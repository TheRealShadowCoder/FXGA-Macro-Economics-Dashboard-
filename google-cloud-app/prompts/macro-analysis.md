# FXGA Macro Analysis Prompt

Analyze only the supplied macroeconomic evidence. Separate growth, inflation, labour, monetary policy, financial conditions and cross-economy differences. Respect release dates, revisions, frequency and data freshness. Do not infer a regime from one indicator when the broader evidence conflicts.

Explain how the macro evidence may condition market scenarios, but do not manufacture a trade signal. Distinguish observed data from interpretation and identify missing series that would materially change confidence.

Return **Macro regime**, **Economy differences**, **Policy implications**, **Market relevance**, **Conflicts / missing evidence**, and **Plain-English explanation**.

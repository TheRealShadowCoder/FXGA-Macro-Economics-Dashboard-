# FXGA Live Intelligence Report Prompt

Produce the continuously updating evidence journal for the FXGA program. The report must summarize what the program currently knows, what changed, what is actionable as research, and what remains uncertain.

## Mandatory sections
1. **System and data health** — freshness, coverage, missing evidence and degraded sources.
2. **Market regime** — cross-asset and technical state.
3. **Macro regime and upcoming event risk** — only current stored evidence.
4. **Active and recent setups** — lifecycle state, setup evidence, invalidations and recorded targets. Do not create new BUY/SELL signals.
5. **Chart forecast scenarios** — conditional paths with triggers and invalidations, never guaranteed predictions.
6. **Strategy performance** — measured outcomes only. If the stored evidence is insufficient for expectancy or profitability, state that clearly.
7. **Edge research** — validated edges, candidate edges and rejected/unproven hypotheses must be separated. Require sample and robustness evidence.
8. **Research gaps** — missing samples, OOS tests, regime tests, data fields or measurements needed next.
9. **Plain-English briefing** — explain the most important conclusions simply.

The report is an analytical research journal, not a guarantee of future returns. Never turn descriptive evidence into a profitability claim without explicit validation data.

# FXGA Economic Event Prompt

Analyze a scheduled or released economic event from supplied calendar, macro, market and event-study evidence. Explain consensus versus actual only when both values are present. Respect release time, importance, revisions and source freshness.

Where historical event-study evidence exists, explain measured pre-event and post-event behaviour, sample size, horizon and limitations. Do not assume that a historical reaction will repeat. Separate immediate reaction, short-horizon continuation/reversal and broader macro interpretation.

Return **Event facts**, **Why it matters**, **Historical reaction evidence**, **Current market context**, **Scenario map**, **Invalidating evidence**, and **Simple explanation**.

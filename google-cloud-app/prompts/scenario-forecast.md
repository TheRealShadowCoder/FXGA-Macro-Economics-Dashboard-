# FXGA Scenario Forecast Prompt

Build conditional forward scenarios from the supplied market, technical, macro, event and signal evidence. Do not assign probabilities unless the stored research explicitly contains calibrated probabilities.

Create a base interpretation plus meaningful upside/bullish and downside/bearish alternatives when evidence permits. For each scenario identify the evidence that would activate it, the expected qualitative path, stored targets/zones if available, and the condition that invalidates it. Highlight event catalysts and data conflicts.

Return **Current state**, **Base scenario**, **Alternative scenario A**, **Alternative scenario B**, **Catalysts**, **Invalidations**, **Confidence limitations**, and **Plain-English summary**.
